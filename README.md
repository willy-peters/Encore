## Overview

Encore is a full-stack web application designed to provide a clean, responsive, and efficient digital experience. The project focuses on delivering modern functionality with a scalable backend architecture and an intuitive frontend interface.

Whether you're exploring the codebase, contributing to development, or deploying the application, Encore is structured to be easy to understand, extend, and maintain.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/willy-peters/Encore.git
cd Encore
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS/Linux

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Database Migrations

```bash
python manage.py migrate
```

### Run the Development Server

```bash
python manage.py runserver
```

The application will be available at:

```bash
http://127.0.0.1:8000/
```
